PDE Systems

There are various PDE systems. We are working with hyperbolic-parabolic systems.

These are implemented through the various Equation classes.

group Equations

The PDE systems equations are built from a decendant of the EquationBase class.

template<QuantityType Q>
class EquationBase
#include <equations/equations.hpp>

Abstract class defining the Equations interface.

Template Parameters:

Q – A QuantityBase class describing the state-vector

Subclassed by Euler2d< T, Q >, ScalarTransport2d< T, Q >

template<TwoDimensional T, QuantityType Q>
class ScalarTransport2d : public EquationBase<Q>
#include <equations/equations.hpp>

Example equationsystem for twodimensional scalar transport.

It describes the

\[ \frac{\partial q}{\partial t} + a \nabla q =0 \]

equation.

template<TwoDimensional T, QuantityType Q>
class Euler2d : public EquationBase<Q>
