struct ModelBuilderConfig

Configuration parameters for the 1D static envelope builder.

These parameters control the anchor temperature, the inner target temperature, the number of equal-mass zones above the anchor, and the initial guess for the outermost zone mass (DM_N).

double t_anchor

Target temperature at the anchor zone [K].

double t_inner

Number of equal-mass zones above the anchor.

Initial guess for DM_N [M_sun].
