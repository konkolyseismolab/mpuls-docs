Detailed Description
--------------------

This module provides:

- A full static envelope builder (buildStaticEnvelope)

- Bisection-based calibration of the outer zone mass (DM_N)

- Bisection-based calibration of the temperature scaling parameter (h)



The envelope is constructed on a Lagrangian (mass-based) grid produced by grid::build(), and uses the physics configuration stored in :ref:`exhale_struct_structStellarInput` and :ref:`exhale_struct_structConfig`.
