Solution filtering

Although the Kurganov-Tadmor scheme is TVD by itself, the use of difference form geometry and 2nd order accurate source calculation create numeric oscillations. Therefore we filter hign wavenumber oscillations of the solutions. For this we use a Nordlund[1] type filter.

For every quantity of the sate-vector \(\boldsymbol q\) we define a hyperdiffusivity as the diffusion:

(1)\[ \left(\frac{\partial q^l}{\partial t}\right)_{\rm diff} = \sum\limits_i^N \frac{\partial}{\partial x_i} \left[ \nu_i(q^l)) \frac{\partial q^l}{\partial x_i}\right], \]

where \(\nu\) is the hyperdiffusive coeeficient described as:

(2)\[ \nu_i = c_{\rm hyp} \Delta x_i \lambda_{\rm max}(\boldsymbol q) \frac{\underset{3}{\max} \vert \Delta_i^3 q^l \vert}{\underset{3}{\max} \vert \Delta_i^1 q^l \vert}, \]

where the term \(\underset{3}{\max} \vert \Delta_i^3 q^l \vert\) is the maximum third-order finite difference on three neigbouring cells. The difference formulae[2] are

(3)\[\begin{split} (\Delta_i^3 q^l)_{j+1/2} = & 3 (q^l_{j+1}-q^l_j)- (q^l_{j+2} - q^l_{j-1}) \\ (\Delta_i^1 q^l)_{j+1/2} = & q_{j+1}^l - q_j^l \\\end{split}\]
Implementation

The filtering is directly applied in the RightHandSide class through the HyperDiffusion and Diffusion2D classes. The former ipmlements the hyperdiffusion coeffitient and the latter implements the truncated diffusion operator. The standard RightHandSide not uses the diffusion operator, this is reached by using RightHandSideDecorator.

Note

It should be noted, that in this particular case vector-derivatives are not propagated mathematically, i.e., this is a truncated version of the true diffusion operator, and additional source terms are emitted. Also note, that this type of filtering is applied on all variables, and its sole purpose is to supress numerical noise.

Stein, R.F., Nordlund, A., 1998. ApJ 499, 914.

[2]

Vögler, A. et al., 2005. A&A 429, 335.
